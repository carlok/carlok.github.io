[forgepulse](https://github.com/carlok/forgepulse) hit its first tagged
release, [v0.1.0](https://github.com/carlok/forgepulse/releases/tag/v0.1.0):
the self-hosted GitHub traffic dashboard with retained clone and view history,
repository analytics, charts, referrer and path snapshots, and JSONL export.
The release note frames it explicitly as the baseline before the next feature
— human attention ranking, which is already landing on the `develop` branch.
