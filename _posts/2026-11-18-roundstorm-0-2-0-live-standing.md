[Roundstorm](https://github.com/carlok/roundstorm) 0.2.0 is a correctness release with one new thing to watch: while a deliberation runs, the control bar shows where the room stands and what it has cost so far — `P2 v3 · Oil whip · 3 of 4 back it · holding out: Bruno · Cost $0.042`. In a conclave the count is of endorsements of the current version, which is what unanimity is measured against; the cost reads `n/a` when no brain reports one and "at least …" when only some do, since unknown never counts as free, and during a sealed round the line stays hidden so the blind positions are not leaked ([v0.2.0](https://github.com/carlok/roundstorm/releases/tag/v0.2.0), [#75](https://github.com/carlok/roundstorm/pull/75)).

The bug batch came from reading the scheduler, ledger, synthesis, DM path and adapters end to end, and each of the fifteen fixes has a regression test that was mutation-checked — with the fix reverted it fails, 20 mutations and 20 caught ([#73](https://github.com/carlok/roundstorm/pull/73), [2172526](https://github.com/carlok/roundstorm/commit/2172526)). The security one is a tier bypass: a one-to-one chat set to *Full local* gave a researcher capped at *Research* write and shell access with no working directory, and DMs now go through `lowerTier` and `resolveWorkspace` like any other turn. The rest is the deliberation itself: a second question in a room saw a slice of the first run whose size depended on the round number and now sees it in full under its own heading, steers in conclaves are shown, consumed and no longer carried into the room's next run, support is counted at the current version so a conclave that ran to its cap cannot be labelled unanimous, and an `oppose` with a bad label can no longer be merged into the position it contradicted as an endorsement.

The tuning pass moved the seeds, examples and README to `claude-opus-5-5`, `claude-sonnet-5-5`, `claude-fable-5-1` and `claude-haiku-5-5` — each new id checked with a real one-word call, old ids still working so no data needs migrating — and fixed synthesis keeping the first 90,000 characters of a long discussion instead of its final round ([#74](https://github.com/carlok/roundstorm/pull/74), [8aa288c](https://github.com/carlok/roundstorm/commit/8aa288c)). `npm test` stands at 329 passing with 5 UI tests.
