A pass over three READMEs that no longer matched what the repositories are. [red-ink](https://github.com/carlok/red-ink)'s title now names the repository next to the game — "Sublevel Three (red-ink)" — so the page is findable under the name the project uses ([b102897](https://github.com/carlok/red-ink/commit/b102897)); [slop-audit](https://github.com/carlok/slop-audit) had kept "(private)" next to its own link long after it [went public in September](/blog/2026/09/13/slop-audit/), and the line is gone ([6178652](https://github.com/carlok/slop-audit/commit/6178652)).

The [diaz-modulus-lean](https://github.com/carlok/diaz-modulus-lean) change is the substantive one: the README said no new transcendence theorem is claimed and left it there, which read as if the library had no results of its own. It now says the library does have results of its own and links [chapter 14 of the blueprint](https://carlok.github.io/diaz-modulus-lean/chap-14-not-found-in-the-sources.html), "Results not found in the sources read", which lists them and ranks the ones that are not routine — with the note that not found in the sources read is not a claim that they are new ([243169f](https://github.com/carlok/diaz-modulus-lean/commit/243169f)).
