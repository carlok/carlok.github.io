title: "guess-the-move before release: an installable offline page, and a difficulty that follows your play"
date: 2026-11-04
tags: [games, tool]
---

Before [guess-the-move](https://github.com/carlok/guess-the-move) went public the page became installable and offline-capable: a web manifest and icon, a service worker that `make dist` stamps with the build id and the exact URLs of that build, one cache per build, page and dataset network-first, and a new build waiting behind a "Reload" bar instead of replacing the page under you. The web container now copies `dist/` built by `make web-image`, replacing the hand-kept file list whose omission caused the earlier blank-board bug, and the repository got its open-source furniture — SPDX lines on every source file enforced by a test, CONTRIBUTING, SECURITY, issue forms, a PR template, and a "Report a problem with this position" link on the answer card ([#1](https://github.com/carlok/guess-the-move/pull/1), [d962b0a](https://github.com/carlok/guess-the-move/commit/d962b0a)).

The same days added what the trainer actually does. Difficulty can follow your level, picking positions that match it or run a bit harder ([#8](https://github.com/carlok/guess-the-move/pull/8)); on a large screen the board follows the window height and level-sharpening picks on by default ([#3](https://github.com/carlok/guess-the-move/pull/3)); an answer can be saved as an image with its FEN beside it ([#4](https://github.com/carlok/guess-the-move/pull/4)); Settings, How it works and About became pages instead of a side menu ([#5](https://github.com/carlok/guess-the-move/pull/5)); a daily challenge arrives with shareable links ([#9](https://github.com/carlok/guess-the-move/pull/9)) and a system share sheet ([#12](https://github.com/carlok/guess-the-move/pull/12)). The first load was cut three times over — the save-image code, the stats file and the stats charts lazy-load ([#10](https://github.com/carlok/guess-the-move/pull/10)) — and a filter dropdown that overflowed its column and left a blank gap under Skip was fixed before any of it shipped ([#2](https://github.com/carlok/guess-the-move/pull/2)).
