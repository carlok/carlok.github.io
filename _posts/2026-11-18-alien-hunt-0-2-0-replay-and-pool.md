---
title: "alien-hunt 0.2.0: replay a run's claims against a fix for free, and see the pool before paying for it"
date: 2026-11-18
tags: [tool, security]
---

[alien-hunt](https://github.com/carlok/alien-hunt) 0.2.0 turns the search into something auditable after the fact. `alien-hunt replay RUN` re-confirms a run's saved claims with the current check — no model call, no API key — and with `--against <sha>` (or `--against-local`) it confirms the same claims on a second commit, such as an advisory's fix, marking each one *fixed there* or *fires there too*; the second is exactly the case a check alone cannot tell from a defect, a test that comes out true for correct behaviour ([v0.2.0](https://github.com/carlok/alien-hunt/releases/tag/v0.2.0), [#12](https://github.com/carlok/alien-hunt/pull/12)). `alien-hunt pool` is the other half of not spending money blind: it prints the atoms a run keeps and the pairs it would draw for a GitHub commit or a local checkout, and `--arms N` hunts N picks per selection rule from one pool so the score can be asked whether it chooses anything at all ([88e9a89](https://github.com/carlok/alien-hunt/commit/88e9a89), [e141f14](https://github.com/carlok/alien-hunt/commit/e141f14)).

Confirmation also got stricter: the marker must be printed from a branch that a repository result decides, so constant tests, patching, shadowing or mocking the repository, calls made while an import runs, and code outside the library files do not count, and the trace now records the file and line of every function entered, threads included ([6e2fdae](https://github.com/carlok/alien-hunt/commit/6e2fdae), [c72b33a](https://github.com/carlok/alien-hunt/commit/c72b33a)). Every run writes `run.json` — version, target, full commit, container image, seed — before anything else and the report names the version, which is what `replay` reads back ([603478a](https://github.com/carlok/alien-hunt/commit/603478a)).

The measured cost of the atom fixes is stated rather than smoothed: on advisory cases rebuilt that day, reading positional-only, keyword-only, `*args` and `**kwargs` parameters as sources lowered held-out `drawn_hit` from 36.4 % to 35.7 %, so that change was **not** shipped, while what did ship moved `drawn_hit` 35.2 % → 35.4 % on the tuning split (123 cases) and 36.4 % → 36.7 % held out (86), at the price of held-out `atom_hit` falling 66.3 % → 62.8 % because two same-named methods in different classes no longer collapse into one atom — a method's receiver is now dropped by position instead of by the names `self` and `cls` ([5d379eb](https://github.com/carlok/alien-hunt/commit/5d379eb), [d2e8bbd](https://github.com/carlok/alien-hunt/commit/d2e8bbd)). 380 tests pass, and `replay` and `pool` are shown in a subprocess never to import `openai`.
