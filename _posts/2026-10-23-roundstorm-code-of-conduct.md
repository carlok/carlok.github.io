---
title: "roundstorm adopts the Contributor Covenant, with GitHub as the enforcement channel"
date: 2026-10-23
tags: [project]
---

[roundstorm](https://github.com/carlok/roundstorm) now carries a
[`CODE_OF_CONDUCT.md`](https://github.com/carlok/roundstorm/blob/main/CODE_OF_CONDUCT.md):
the Contributor Covenant 2.1 in full, with enforcement routed through GitHub —
a report goes to the maintainer's GitHub contact rather than to an address that
has to be kept current — and a link to it from `CONTRIBUTING.md`
([#63](https://github.com/carlok/roundstorm/pull/63),
[af4bdab](https://github.com/carlok/roundstorm/commit/af4bdab)).
