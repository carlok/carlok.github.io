[pacenotch](https://github.com/carlok/pacenotch) got its Windows build path from someone else: [matteodesimone](https://github.com/matteodesimone) — the same login that [forked the project in October](/blog/2026/10/28/pacenotch-fork-matteodesimone-tray-yellow/) — opened [#5](https://github.com/carlok/pacenotch/pull/5) adding `scripts/build-windows.ps1` for Windows users who have Go and gcc but no `make` or bash ([e4b0659](https://github.com/carlok/pacenotch/commit/e4b0659)). It builds `dist/pacenotch_windows_<arch>.exe` with `CGO_ENABLED=0` and `dist/pacenotch-gui_windows_<arch>.exe` with `-tags gui -H=windowsgui`, takes the version from `-Version`, `$env:VERSION` or `git describe` and falls back to `dev` when git is absent, stops early with a hint when `go` or `gcc` is missing, and puts the caller's `CGO_ENABLED`, `GOOS`, `GOARCH` and working directory back when it finishes; it is ASCII and free of PowerShell 7-only syntax so it runs under 5.1 too, tested on Windows 11 with Go 1.27.4 and MinGW-w64 gcc 16.2.

Two of mine followed on the same day. Fyne 2.8.2 and Go 1.27.4, with `golang.org/x/sys` and `x/term` — the release fixes a Wayland crash on long labels, a blank window after minimising on Windows and pixel gaps between adjacent rectangles, and leaves the vendored systray patch and the README screenshots untouched ([6546c8a](https://github.com/carlok/pacenotch/commit/6546c8a)). And a tuning pass ([#7](https://github.com/carlok/pacenotch/pull/7), [391b883](https://github.com/carlok/pacenotch/commit/391b883)): an update check that fails because the machine is offline now retries after an hour instead of waiting a day, while rate limits and bad responses still wait the day; About says pacenotch asks GitHub once a day for the latest release, and the About window and its screenshots are taller to fit the line; CI gets `timeout-minutes` on every job, fuzz runs on Linux only, the Windows job builds the CLI through the new script, and releases now open with a "which file" table from `.github/release-notes-header.md`.
