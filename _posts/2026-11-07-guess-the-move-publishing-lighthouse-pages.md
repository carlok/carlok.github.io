title: "guess-the-move goes live on GitHub Pages: Lighthouse from 63 to 92, three browsers in CI, and a link-preview card"
date: 2026-11-07
tags: [games, tool, github]
---

The four days after [guess-the-move went public](/blog/2026/11/03/guess-the-move-public/) went into making it publishable. Lighthouse on the real build scored 63 and now scores 92, with a budget check alongside it ([#20](https://github.com/carlok/guess-the-move/pull/20), [8e1bedd](https://github.com/carlok/guess-the-move/commit/8e1bedd)); the browser specs run in Firefox and WebKit as well as Chrome ([#21](https://github.com/carlok/guess-the-move/pull/21), [8033601](https://github.com/carlok/guess-the-move/commit/8033601)); the comparison table orders its rows from best to worst with Stockfish first ([#23](https://github.com/carlok/guess-the-move/pull/23), [ef7f823](https://github.com/carlok/guess-the-move/commit/ef7f823)); and a first play no longer waits for the whole dataset — a 24-position sample of about 20 KB gzipped is fetched first and the full file swaps in behind it ([#24](https://github.com/carlok/guess-the-move/pull/24), [07cd9e7](https://github.com/carlok/guess-the-move/commit/07cd9e7)).

Publishing followed: the repository was prepared for release ([#25](https://github.com/carlok/guess-the-move/pull/25), [fcca2e8](https://github.com/carlok/guess-the-move/commit/fcca2e8)), the site deployed to GitHub Pages and is live at [carlok.github.io/guess-the-move](https://carlok.github.io/guess-the-move/) ([#26](https://github.com/carlok/guess-the-move/pull/26), [c2ea249](https://github.com/carlok/guess-the-move/commit/c2ea249)), a test now pins what happens when a reload lands while the service worker is still installing — the preloaded data has to be the data used ([#27](https://github.com/carlok/guess-the-move/pull/27), [392cafa](https://github.com/carlok/guess-the-move/commit/392cafa)) — and the page carries a 1200×630 link-preview picture with Open Graph and Twitter tags ([#28](https://github.com/carlok/guess-the-move/pull/28), [b4c9147](https://github.com/carlok/guess-the-move/commit/b4c9147)).
